# Chess sound sources

The start, move, check, and checkmate cues use real chess foley, and success
uses a real crowd response. Sources are released under
[Creative Commons Zero 1.0](https://creativecommons.org/publicdomain/zero/1.0/),
except where the table names
[Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
The checked-in preview files make the sound build reproducible without a runtime download.
